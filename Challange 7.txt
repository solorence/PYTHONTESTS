Challenge 7 — Nested decisions

Now let's combine conditions + dictionaries + lists + strings + numbers.

Use this:

employees = [
    {'name': 'John', 'age': 34, 'salary': 75000, 'active': True},
    {'name': 'Mary', 'age': 28, 'salary': 68000, 'active': True},
    {'name': 'Peter', 'age': 41, 'salary': 92000, 'active': False},
    {'name': 'Grace', 'age': 31, 'salary': 81000, 'active': True},
    {'name': 'David', 'age': 24, 'salary': 55000, 'active': False}
]

Create:

result = {
    'senior': [],
    'junior': [],
    'high_earner': [],
    'inactive': []
}

For every employee:

1. If age is 30 or above, put their name in senior.


2. Otherwise, put their name in junior.


3. If salary is 80,000 or above, put their name in high_earner.


4. If they are not active, put their name in inactive.



Then print the dictionary.

Expected result

You should be able to work out the exact names yourself.

Restriction: Don't use comprehensions, set(), max(), min(), or anything new.

This one is intentionally simpler than Challenge 5. I want to see whether you can now apply conditions cleanly without getting tangled in the logic.

Send your code when you're ready.
